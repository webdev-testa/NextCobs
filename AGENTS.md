# UI Component Development Workflow

Whenever asked to create, design, scaffold, or implement any UI component (e.g., hero sections, bento grids, pricing cards, feature blocks, carousels, dialogs, navbars, forms):

1. **Mandatory 21st.dev Search First**:
   - Before writing component markup or CSS from scratch, ALWAYS query the 21st MCP server (using search or get_inspiration) to find top community components matching the request.
2. **Fetch and Adapt**:
   - Retrieve the best-matching component code (get).
   - Adapt and refactor the code to match this project's stack, theme, Tailwind utilities, and design tokens.
3. **Build From Scratch Only as Fallback**:
   - Only code completely from scratch if no suitable component or pattern is found on 21st.dev.
